{{/* --------------------------------------------------------------------------- pnp/channel.html - one post drawn as a "channel" row (the CHNN lines on the homepage and posts list). Usually called in a loop by pnp/channels.html. Arguments (passed as a dict): page = the post page i = its 0-based index in the list (used for the CH01, CH02... number) max = the biggest word count in the whole list (so the little signal-bar can be drawn as a percentage of the longest post) The row links to the post, and data-tune / data-tune-label make hovering it tune the waterfall to this post's band (see waterfall.js). ---------------------------------------------------------------------------- */}} {{ $p := .page }} {{ $cat := "" }}{{ with $p.Params.categories }}{{ $cat = index . 0 }}{{ end }} {{/* use the post's first category as its band */}} {{ $f := partial "pnp/freq.html" ($cat | default "default") }} {{/* look up that band's freq + waterfall position */}} {{/* Channel number = this post's chronological rank among ALL posts, oldest = CH01. It's a stable ID: it doesn't depend on the display order or which slice we're showing, so a post keeps its number forever and a new post just takes the next one up. */}} {{ $all := (where site.RegularPages "Section" "posts").ByDate }} {{/* every post, oldest first */}} {{ $num := 0 }}{{ range $idx, $pg := $all }}{{ if eq $pg.RelPermalink $p.RelPermalink }}{{ $num = add $idx 1 }}{{ end }}{{ end }} {{/* find this post's 1-based position */}} CH{{ printf "%02d" $num }} {{/* stable channel number, zero-padded: CH01 = oldest post */}} {{ $p.Title }} {{/* post title */}} {{ $p.Date.Format "2006-01-02" }} · {{ with $cat }}{{ . }} · {{ end }}{{ $f.freq }} · {{ $p.ReadingTime }} min {{/* date · category · freq · read time */}} {{/* signal-strength meter: bar width = this post's words as a % of the longest post (min 1 to avoid divide-by-zero) */}} {{ $p.WordCount }} words
